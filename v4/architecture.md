# 结构即智能：PRIMORDIA v4 —— 均值场上的基元社会

> 版本 4.1 ｜ 配套实现：primitives.py · evolution_engine.py · communication_layer.py · run.py
> 运行要求：任意安装 Python ≥ 3.8 的普通电脑；零第三方依赖；纯 CPU；不依赖任何现有 LLM。
> 本文档描述的每一条机制都对应可运行的代码，每一处声明都附带可核对的量化证据。

## 0. 设计立场

本架构不追求一个更大的语言模型，而是构造另一种智能存在形态：

> **智能不是参数堆砌，而是结构在时间维度上的自我优化过程。**

因此系统中不存在"被训练的模型"，只存在**正在生活的结构**。感知、行动、记忆、
监察、工具——没有一样是预装模块，全部从一个均匀的基元群体中**自发分化**而成。
设计者只提供两样东西：物理定律（五条自然规则）与化学介质（共享场）。
不提供控制器、目标函数、损失函数或优化器。

三条设计边界（对应任务要求）：

1. 在普通电脑上运行：纯标准库，实测约 **1000–1400 拍/秒**（单核笔记本级 CPU）；
2. 不依赖任何现有 LLM 作为核心；
3. 构建的不是语言模型，而是自主智能体。

## 1. 总体形态：基元社会 + 共享场 + 自然法则

```
            ┌────────────────────────────────────────────────┐
            │                 外部观察者（人类）                │
            └───────▲───────────────────────────┬────────────┘
                    │ 自述报告 / 对话 / 纠正      │ 观察与指令
            ┌───────┴──────────┐      ┌─────────▼─────────┐
            │  Reporter 渲染器  │◄────►│   Parser 解析器    │   communication_layer.py
            └───────▲──────────┘      └─────────┬─────────┘
                    │ 只读统计（单向玻璃）         │ 校正脉冲 / 约束册 / 教导注入
  ══════════════════╪═══════════════════════════╪══════════════
  演化引擎（自然法则层，非控制器）                  │
    法则1 赫伯加强   法则2 能量竞争   法则3 自适应阈值 │  evolution_engine.py
    法则4 内在可塑性 法则5 侧向抑制   生老病死 / 工具锻造│
  ══════════════════╪═══════════════════════════╪══════════════
            ┌───────┴──────────────────────────▼────────────┐
            │       基元群体 Population（无层级、平等）         │
            │   sensor ×n   assoc ×n   memory ×n             │   primitives.py
            │   meta ×n     effect ×n（可逆工具执行者/宏）      │
            └───────┬────────────────────────────────────────┘
                    │ 发射 → 无偏均值聚合
            ┌───────▼────────────────────────────────────────┐
            │        共享场 FieldMedium（K=8 通道连续介质）      │
            └───────┬────────────────────────────────────────┘
                    │ 观测注入 / 行动作用于
            ┌───────▼────────┐
            │  ResourceEnv     │（"可预测性即资源"的小世界）
            └────────────────┘
```

三个本体层：

1. **介质层**：K=8 通道共享连续场。任何基元的影响只能通过场传播。
2. **个体层**：自治基元。每个基元是独立动力学实体，自带基因组（自我描述）、
   局部状态、局部更新规则与能量账本。
3. **法则层**：演化引擎。它不是中枢——像物理定律一样对所有基元一视同仁地施加
   同一条规则，从不点名、从不排序、从不路由。

## 2. 基元定义（primitives.py）

### 2.1 统一结构

| 部分 | 内容 |
|---|---|
| 基因组 Genome | 种类 kind、地址向量 address∈{-1,0,1}^8（嗓音）、增益 gain、初生阈值 θ₀、目标发放率 ρ*、工具名、宏配方、亲代、出生拍、代数、变异计数 —— **即自我描述** |
| 局部状态 | 势 p、阈值 θ、能量 e、爆发值 burst、不应期、发放率 EMA、侧抑制待吸收量、键表 bonds |
| 单步预测器 | 对自身最敏感通道做指数滑动预测 → 惊讶度 → **胜任度 comp = exp(−err/σ)** |
| 行为接口 | update() 局部动力学 · learn() 预测学习 · emit() 向场发射 · mutate() 自我变异 · mitosis_child() 有丝分裂 · describe() 自述 |

### 2.2 五种分化型及其特殊关系

| 型 | 特有行为 | 在社会中的关系 |
|---|---|---|
| sensor 感知 | 听取环境编码向量（多尺度正弦码） | **世界的唯一入口**：外部世界只能经它触碰场 |
| assoc 关联 | 纯内部耦合动力学 | 初始多数，结构生长的主体材料 |
| memory 记忆 | 发放时存场快照（环形缓冲48），寂静时低概率**重放巩固** | 与全体构成"经验—回忆"环 |
| meta 监察 | 接收引擎推送的全局唤醒度/收益变化快照 | 自述报告的数据锚点、自我修正的感受器 |
| effect 执行 | 携带工具名或宏配方，以势能 tanh(p) 提出动议 | **世界唯一出口**：原生安全门在其执行入口内部 |

### 2.3 原生安全（编码在定义里，而非外挂过滤器）

1. **可逆性登记**：每个工具在 ACTION_SPECS 中声明 reversible；
2. **物理性阻断**：不可逆动作的执行入口直接检查确认令牌，缺失即抛
   IrreversibleBlocked —— 不是"被拦截"，是该基元**物理上做不出**这个动作；
3. **多层确认**（不可逆动作需同时满足）：监察法定票 + 人类显式令牌 + 意图与回滚方案入册；
4. **有界性**：p、θ、gain、ρ*、能量、种群规模皆有硬边界；变异为小步有界突变；
5. **约束册**：人类纠正形成的 (动作族, 情境) 记录使同类动议**丧失合格性**，
   且被纠正行动的问责窗参与者被扣能与敏化——纠正由此进入演化方向。

## 3. 通信的唯一方式：无偏均值聚合

**这是全架构最强的约束，也是分化的根源。**

每一拍，场的每个通道取全体存活基元贡献的算术平均：

```
field[c] = ( Σᵢ burstᵢ · addressᵢ[c] ) / N        （N = 全体存活基元数）
```

没有加权、没有路由、没有注意力、没有优先级、没有排序选择。
沉默者的 0 与喧哗者的 1 以同一分母进入平均。基元间的影响天然对称、天然无偏。

两点澄清（诚实工程注记）：

- EMIT_SCALE=5 是**场的公共单位制**：对每个基元的贡献乘同一个常数，
  如同选择计量单位，不改变任何基元相对他人的影响力，均值仍无偏；
- 地址向量 address 是基元**自己的嗓音与听力**，属于其内在身份的一部分；
  它决定"谁与谁同相"，绝不构成对他人贡献的标量加权。

差异从何而来？对称破缺来自动力学而非接线：内在热噪声（NOISE_STD=0.06，人人相同）
与环境编码在均值耦合下被五条自然规则放大为宏观结构——如同均匀流体外涌出对流胞。

## 4. 演化机制（evolution_engine.py）

### 4.1 五条自然规则（每拍对全体施加同一套）

| 法则 | 数学形式 | 作用 |
|---|---|---|
| 1 赫伯加强 | 共燃窗口内 pair 计数 ≥ τ_bond(6) ⇒ 双侧缔键（无权重拓扑边）；键计数每拍 ×0.995，<0.8 拆除 | "谁与谁相邻"，绝不参与信号强度 |
| 2 能量竞争 | 收入端只有环境的可预测性收益 income = I₀·(0.35+0.65·稳定度)·(0.45+0.55·带内贴近度)；每拍**按人头均分红利**；维持/发放/键维护皆耗能 | 多一张嘴红利薄一分；无用结构收不抵支自然溶解。引擎从不排名，淘汰由每个基元自己的账本决定 |
| 3 自适应阈值 | θ ← θ + η·(rate_EMA − ρ*)，θ∈[0.05,3] | 过活跃者自动沉默，失聪者自动敏化 |
| 4 内在可塑性 | 已发放者以 p ∝ 0.02·(0.5+惊讶度) 变异基因组（地址翻转一位、增益±5%、ρ*±10%） | 新结构由旧结构生育并突变而来 |
| 5 侧向抑制 | 发放者向键邻居注入抑制量 0.15，下一拍吸收 | 功能重叠近邻互相压制，逼迫分化 |

### 4.2 生命周期

- **生（有丝分裂）**：e ≥ 14 且种群 < 140 时自行分裂，亲子各半能量，子代基因组经法则4变异并继承工具/配方；
- **死（溶解）**：e ≤ 0 移除，双侧键同步拆除；
- **再分化保全**：某分化型灭绝时，最富关联基元按局部规则转化为该型（诚实记录 DIFFERENTIATION 事件）；
- **原始汤（诚实声明的边界条件）**：种群跌破 12 时注入新关联基元并记录 PRIMORDIAL_RESEED——这是防止数值灭绝的护栏，不是智能的一部分。

### 4.3 工具锻造（ToolForge）：系统创建自己的工具

1. 锻造炉监视**落选但真诚的动议**（支持度过线却未获通过者），按动作族累计冷寂次数；
2. 同族冷寂 ≥ 3 次，且历史成功日志中存在出现 ≥ 3 次的可逆步骤序列（长度 2–3）时，将其复合为宏配方；
3. 配方在克隆环境中**干跑验证**（步步可逆 ⇒ 宏必可逆）；
4. 通过后由最富关联基元**有丝分裂**诞生一名携带宏配方的新执行基元，记 TOOL_FORGED 事件。

能力边界因此不是静态的：需要什么工具，社会就长出什么工具。

## 5. 集体决策与透明沟通

### 5.1 法定人数表决（Quorum）

每 40 拍或集体唤醒度 > 0.55 时：

1. 合格执行基元以 support = tanh(p) 提交动议（合格性 = 能量足 + 不应期外 + 未被约束册否决）；
2. 最高支持度当选；并列时**公平抽签**（仍是无偏聚合）；
3. 可逆动作立即执行；不可逆动作撞上原生安全门，被拒绝并记录；
4. 执行前后各测一次带内贴近度，改善量为正则按**胜者结构联盟均分**奖励（无偏份额）；
   全体参与动议者记入**问责窗**，供后续纠正追溯；
5. 落选动议进入锻造炉的需求账本。

### 5.2 通信协议（communication_layer.py）

Reporter 是架在统计事实上的一块单向玻璃：一切语句由 MetricsRegistry 与事件流的
量化事实即时渲染，每个数字都可对照 growth_log.jsonl 核验，拒绝空泛表述。

| 意图 | 触发词 | 回复内容 |
|---|---|---|
| 状态报告 | 报告/状态/体检 | 种群、键数、连通片、能量经济、胜任度、唤醒度、世界状态……全带数字 |
| 解释 | 为什么/解释 | 最近集体行动完整因果链：触发、胜出动议与边际、法定过程、执行序列、prox 变化、奖励均分 |
| 工具清单 | 工具 | 内置工具可逆性 + 当前持有者 + 宏配方 + 锻造统计 + 使用计数 |
| 成长总结 | 成长/演化史 | 早/近期指标对比（↑↓≈）+ 里程碑时间线（首键/首裂/工具诞生/自修/纠正） |
| 自我描述 | 你是谁 | 种群构成、多数型格言、累计变异、最年长者、最胜任成员的自我刻画 |
| 教导 | 教：<文本> | 脉冲注入感知层 + 入记忆与事件流 |
| 纠正 | 纠正：<动作>[理由] | 约束册生效数、问责窗受罚人数、阈值上调幅度 |
| 表扬 | 表扬：<动作>[理由] | 反向：奖能与敏化、放宽约束一条 |
| 节奏/暂停/继续 | 加速/减速 n、暂停、继续 | 动力学冻结与恢复 |
| 看板/保存/退出 | 同名 | ANSI 快照 / JSONL 快照 / 存档离开 |

解析失败时诚实告知可用指令集，把自由文本作为环境低语注入，**绝不编造**。

## 9. 运行指南

**双击即可体验**（推荐普通用户）：

- 双击 `启动AGI.bat` —— 进入交互模式，与基元社会对话；
- 双击 `演示模式.bat` —— 观看 1500 拍自主演化演示与终期报告。

两个启动器均自动处理 UTF-8 编码，结束时窗口停在按键等待，不会自动关闭。

命令行方式：

```
python run.py                          # 自主演化演示（headless 1500 拍 + 终期报告）
python run.py --ticks 3000 --seed 21   # 更长的独立历史
python run.py --mode live              # 交互：后台持续思考 + 人机对话
python run.py --mode selftest          # 机械自检（9 项断言）
python run.py --resume out/snapshot.json   # 从快照续演
```

live 模式下先说『帮助』；试着教它一句话、表扬一次成功的 probe、
纠正一次鲁莽的 nudge——然后问它『为什么』。

## 11. 诚实声明（本架构不是什么）

- 它此刻的能力上限是"在可预测性即资源的小世界里谋生、结社、制器、自述"，
  尚不具备人类水平的语言理解；
- meta 监察基元接收的全球快照、以及 MIN_POP 原始汤补种，是显式声明的边界条件，
  不是隐藏的中心控制——它们分别记录在每拍驱动项与 PRIMORDIAL_RESEED 事件里；
- 但它的每一点能力都是**长出来的，而不是写进去的**：
  没有任何一行代码告诉它"先 probe 再 nudge"、
  没有任何一行代码知道"nudge_plus→nudge_plus"该成为一个工具。
  这些是结构在时间里自己优化的结果——这正是本架构对"结构即智能"的全部辩护。
