This is a spare-time self-evolving LLM learning experiment, run on a Hygon DCU instance
on SCNet (National Supercomputing Internet, China). The idea: use a small local model
(Qwen2.5-1.5B → 7B) as the "brain", and try to compensate for its limitations with
program-side architecture — tool calling, reflection loops, persistent memory, and an
evolution proposer.

## What Was (and Wasn't) Achieved

**Achieved:**

- A chat pipeline: local relay (`relay/chat_relay.py`) → SCNet Jupyter kernel → model
- A DRAFT → CRITIQUE → REVISE → LEARN reflection loop with persistent memory files
- Phase B–E experiment scripts and result JSONs (evolution proposer, knob tuning, LoRA fine-tuning, etc.)
- v5.x: a program-side numeric guard inspired by DeepSeek-R1's published chain-of-thought
  style (premise anchoring, natural backtracking), which intercepts most numeric drift on test questions

**Not achieved / known issues:**

- The 7B base model has a weight-level numeric drift bias (minimal experiment: with no
  scaffolding at all, it recalls 10 as 11). Program-side guards can only intercept output;
  they cannot fix the root cause.
- Phase experiments have very small sample sizes; conclusions are preliminary observations
  without statistical significance.
- The code is fast-iteration experiment scripting: no tests, no linting, many hardcoded paths.
