# 不堆参数的智能：小模型自进化的三条程序侧架构路线

**——LLM 编排、结构动力学与认知架构的组合实证探索**

> 性质声明：这是一篇**个人业余实验的技术报告**。所有实验样本量小、环境单一，结论仅为初步观察，不构成统计意义上的科研结论。完整免责声明见 [DISCLAIMER.md](DISCLAIMER.md)。

## 摘要

个人研究者无法负担大规模训练，但能否利用**程序侧架构**（program-side architecture）——即不改变模型权重、在模型外围构建计算结构——让小模型乃至无参数的结构系统表现出超越其原始能力的行为？本文记录了围绕这一问题的三条技术路线的完整探索：（A）以 Qwen2.5 系列模型为认知核心的 **LLM 编排式自进化系统**，通过工具调用、DRAFT→CRITIQUE→REVISE→LEARN 反思循环与九层进化提案器实现自我改进；（B）**结构动力学**路线的"基元社会"：无中心、无权重、无外部优化器，仅由均值场交互与五条自然规则驱动结构演化，并涌现出宏工具；（C）**五件套认知架构**参考实现：持续学习引擎、分层记忆、内生世界模型、元认知调度与内生动机的正交组合。本文报告了各路线的可复现机制设计、量化观察（如编排循环使任务成功率从 0.50 提升至 0.83 的同时出现回滚-恢复行为；提示策略对 1.5B 小模型的反直觉负效应；3000 个周期内宏工具的自发涌现），以及跨路线比较得出的三点讨论：脚手架收益的不对称迁移、思维链提示对小模型数学任务的负效应、以及"验证闭环缺位"作为三条路线共同的薄弱环节。全部代码、实验产物与脱敏后的快照已在 GitHub 仓库公开。

**关键词**：自进化智能体；小语言模型；程序侧架构；结构动力学；持续学习；反思循环；元认知

## 1 引言

### 1.1 动机

当前大语言模型（LLM）的能力增长高度依赖算力与数据规模。对于无法接触预训练基础设施的个人研究者，一个自然的问题是：**在不训练（或仅轻量训练）模型权重的前提下，架构与工程手段能把系统的有效智能推到多远？**

这一问题的价值不止于"穷人的替代品"：

1. 若程序侧脚手架能稳定补偿小模型的能力缺陷，则说明相当一部分智能表现是**架构性质而非参数性质**；
2. 反之，若某些缺陷（如下文报告的数字漂移）被证实为**权重级偏见**、脚手架只能拦截不能消除，这本身就是对小模型能力边界的有价值刻画；
3. 更进一步：完全放弃 LLM，纯结构动力学系统能否产生最原始意义的"智能行为"（预测、工具使用、自我维持）？这构成对"智能是否必须以语言模型为载体"的对照检验。

### 1.2 三条路线的设计立场

| | 路线 A：LLM 编排 | 路线 B：结构动力学 | 路线 C：认知架构 |
|---|---|---|---|
| 代表系统 | AGI Research & Evolution OS（v1） | SEED OS → 基元社会 → PRIMORDIA（v2–v4） | 五件套认知架构（v5） |
| 智能载体 | 一个大语言模型 | 均值场上的基元结构 | 认知部件的正交组合 |
| 是否依赖现有 LLM | 是 | 否（刻意边界） | 否（预留挂载点） |
| 学习发生在哪 | 提示词 / 组件配置层（LoRA 为辅） | 键拓扑 / 种群 / 宏工具配方 | 在线权重更新 + 记忆系统 |
| 硬件 | SCNet 海光 DCU 远端实例 | 普通 CPU | 普通 CPU |

三条路线共享同一个评价哲学：**每一条机制声明都应对应可运行的代码和可核对的证据**。这也是本文只报告仓库中实际存在产物的实验的原因。

## 2 相关基础

路线 A 站在 LLM 智能体工程的既有实践之上：ReAct 式的工具调用交替 [10]、Reflexion [11] 与 Self-Refine [12] 式的语言化自我批评、以及以 LLM 自身作为变异器的进化搜索 [13]。路线 B 的直接思想源头是 Minsky 的心智社会 [1] 与 Hebb 式的无监督共现学习 [2]，其"无偏均值聚合"取自平均场简化；"基元自发分化与死亡"则与神经结构可塑性（分裂/剪枝）一脉相承。路线 C 的五个部件分别对应持续学习中的弹性权重巩固思想 [5]、互补学习系统理论（海马体–新皮层双系统）、基于想象的内部世界模型规划、System 1/System 2 双过程理论 [3]，以及以预测误差为内在奖励的好奇心研究传统。评测方面使用了 GSM8K 风格的小学数学任务 [7] 与 AG News 文本分类 [8]。

## 3 路线 A：LLM 编排式自进化系统

### 3.1 系统架构

系统部署于 SCNet 海光 DCU 实例（PyTorch 2.9 ROCm 后端），由三部分组成：

1. **本地中继（relay）**：`chat_relay.py` 作为对话门，经 Jupyter 内核通道调用远端推理内核（`rsh.py` 执行远端命令）；本地侧禁用代理直连以规避链路干扰；
2. **云端核心（remote）**：`agi_core.py`（认知主循环）、`evolution_loop.py`（九层进化回路：L1 提示词 → … → L9 架构）、`tool_system.py`（真实联网与计算的标准化执行器）、`world_model.py`（潜空间预测与想象）、`memory_system.py` 与八个 sqlite 进化记忆库；
3. **进化提案器**：Phase C 起引入 Qwen2.5-1.5B-Instruct 作为独立提案模型，从轨迹失败统计中生成改进假设。

反思循环采用 **DRAFT → CRITIQUE → REVISE → LEARN** 四步：模型先答，再显式自我批评，修订后落盘经验；每次进化的候选改动需经过沙箱验证与基准门（benchmark gate），回归超过阈值即触发自动回滚。

### 3.2 实验：自进化循环的行为学

#### 3.2.1 Phase B：首次点火与回滚恢复

以带校验的计算任务流（初始成功率约 0.5）为对象，40 任务/周期的进化运行产生了如下轨迹（`phase_b_first_fire.json`）：

| 进化周期 | 改动 | 成功率 |
|---|---|---|
| C0 基线 | 无校验、无重试 | 0.500 |
| C1 | 接受「启用校验 + retries=2」 | 0.825 |
| C4 | 回滚触发（回归 0.0833）后恢复 | 稳定版 v_0aa6030a |

全程累计 360 条轨迹，提出 6 项改进，接受 3 项、拒绝 1 项；一次回归被基准门拦截并成功回滚。**值得强调的是回滚事件本身**：系统并非单调上升，而是经历了「改进 → 回归 → 检测 → 回滚 → 恢复」的完整安全行为链，这正是进化式自我修改系统最需要验证的性质。

#### 3.2.2 Phase B-transfer：脚手架收益的不对称迁移

在两个任务族上分别进化出最优配置后交叉部署（120 训练 / 600 评估）：

| 迁移方向 | 本族最优成功率 | 异族部署成功率 | 迁移比 |
|---|---|---|---|
| A\* → B | 0.9567（B 本族同为 0.9567） | 0.9567 | **1.00** |
| B\* → A | 0.9517（A 本族） | 0.4700 | **0.49** |

**发现：脚手架配置的收益是不对称的。**「重校验型」配置可以无损迁移到另一任务族（因为校验的代价与任务分布解耦），而「多重试型」配置离开其适配的失败模式后近乎失效。此外，基准门还自动否决了「把 retries 从 4 降到 0 以省算力」的提议——省资源类目标若无正确性约束会被门自然挡下。这一现象提示：**为自进化系统设计的验收门本身决定了进化的安全性边界**。

#### 3.2.3 Phase C：1.5B 小模型担任进化提案器

用 Qwen2.5-1.5B-Instruct 替换人工规则作为提案生成器（`phase_c_llm_proposer.json`），任务族 A 的成功率仍从基线 0.4833 升至 0.8333（C1），表明**提案生成不需要强模型**——从失败统计中归纳假设属于小模型能力圈内的任务。

#### 3.2.4 负结果：提示策略对 1.5B 数学任务的反直觉效应

在 GSM8K 风格数学题上对 9 种提示策略做了系统扫描（`phase_e1_lora.json` 的 d2_archive 段，Qwen2.5 小模型）：

| 策略 | 准确率 |
|---|---|
| S0 直接简洁作答 | **0.38** |
| S1 思维链（逐步计算） | 0.26 |
| S2 思维链 + 校验 | 0.21 |
| S3 分解 + 思维链 | 0.28 |
| S5 模式识别启发 | 0.17 |

**所有"更聪明"的提示策略均劣于直接作答。**一个可能的解释与小模型的数字漂移偏见一致（见 3.2.5）：更长的思维链意味着更多次数字生成机会，每次生成都暴露于漂移风险，误差在链条中复合；校验环节若同样依赖该模型，等于让有偏见的生成器检查自己。这与"思维链普遍有益"的直觉相反，提示**思维链收益存在模型规模下限**。样本量有限，此观察待更大规模复核。

#### 3.2.5 数字漂移：一个权重级偏见的个案

最小化实验显示：7B 基座在无任何脚手架时会把「10」复述成「11」。据此实现的程序侧数字守卫（借鉴 DeepSeek-R1 公开的思维链风格 [4]：前提锚定、自然回溯）能在测试题上拦截大部分数字漂移，但**无法消除根源**——守卫只能拦输出。这是路线 A 最重要的诚实结论之一：脚手架是护栏不是治疗。

#### 3.2.6 仿生 LLM 的结构可塑性消融（DCU）

`v8_ablation.json` 记录了 9 组配置 × 800 步的 DCU 消融：单步约 27.7 s（cuda），最终损失收敛至 ~1.97（最佳验证 ~1.76）；运行期间网络发生 **268 次分裂与 68 次剪枝**，活跃神经元数从 64 增长到 114；类别化 token 迁移探针 24 次中 top1 命中 8 次、top5 命中 14 次（中文/英文类别未命中，符合语料构成预期）。这证明结构可塑性机制在国产加速器上可运行，但泛化探针成绩也如实显示了该原型的局限。

## 4 路线 B：结构动力学的基元社会

### 4.1 设计哲学：结构即智能

路线 B 彻底移除了 LLM：系统中不存在"被训练的模型"，只存在**正在生活的结构**。基元（Primitive）只有统一的三元能力——自我描述、局部状态更新、对外交互；信号传递无权重、无路由、无注意力，唯一的信息通道是对成员发射信号做**无偏均值聚合**的场（Field）。结构的全部信息保存在"谁在哪个场里"这一拓扑中。

### 4.2 三代迭代

- **SEED OS v2.2（v2）**：五类基元（感知/计算/行动/镜像/工具）× 五条自然规则；镜像基元与全体构成"观察–预测环"，其预测误差是系统自我修正的触发器；配「语言皮层」——对百万级过滤语料（Belle 中文对话集 [9]）建立的 2-gram 倒排联想索引，提供四级置信度的应答（确定/猜测/联想/边缘）。
- **基元社会 v3.1（v3）**：引入能量经济（可预测性收益→红利→有丝分裂）、法定人数表决（唤醒度过线 → 支持度 = tanh(rate/ρ\*) 投票 → 联盟均分奖惩）与**原生安全**——动作的可逆性写在类定义里，无令牌的基元物理上做不出不可逆动作；监察基元需 2/3 清醒 + 人类令牌方可放行高危操作。实测纯 CPU 吞吐 250–400 拍/秒，附 10 项自检。
- **PRIMORDIA v4.1（v4）**：同一哲学的量化证据强化版，每条机制声明附带可核对的实验证据。

### 4.3 涌现证据：宏工具的自发诞生

v4 快照（tick 3000）记录了一次完整的工具涌现：系统在追踪移动目标的任务中，由 ToolForge 监视到反复出现的冷寂动议签名，将三个 `probe` 行动固化为宏工具配方 `macro:nudge_minus_1`，此后该宏工具作为一等公民参与表决（行动计数：probe 13、nudge_minus 9、**macro:nudge_minus_1 3**、nudge_plus 3）。同期种群动态：诞生 18、死亡 0。

**这不是被编程的工具，而是被选择的工具**：配方来自对历史行为的统计固化，去留由后续表决的经济奖惩决定。这是路线 B 对「无 LLM 条件下能否产生新功能结构」问题的肯定性回答——尽管规模与通用性与 LLM 工具不可同日而语。

## 5 路线 C：五件套认知架构

### 5.1 模块映射

路线 C 把一场关于「什么才算 AGI 架构」的设计讨论落成纯 numpy 可运行的参考实现，五个正交部件对应认知科学的标准分工：

| 蓝图 | 模块 | 核心机制 |
|---|---|---|
| 持续学习引擎 | `learning.py` | 在线小步更新 + 优先回放 + 周期性睡眠巩固（以 L2-SP 锚定 [6] 替代 EWC 的诚实简化） |
| 分层记忆系统 | `memory.py` | 工作/情景/语义/程序四层；显著性淘汰、相似度×近因检索、Beta 技能统计 |
| 内生世界模型 | `world_model.py` | 动力学预测、反事实模拟（想象）、类别 CEM 规划 |
| 元认知调度器 | `metacognition.py` | 快慢路由 + 三重停车条件（信心/预算/反刍闸门） |
| 内生动机系统 | `motivation.py` | 好奇心（预测误差内在奖励）、目标栈（探索/利用）、胜任感 |

认知周期为：感知 → 动机 → 决策 → 行动 → 学习 → 记忆 → 睡眠；决策采用 System-1 直觉草案 + System-2 模型内验证修正的双过程结构 [3]。

### 5.2 评测设计：非平稳世界

演示场景为 8×8 非平稳 GridWorld：**每 150 步重排墙壁与目标**——世界会变，智能体必须靠持续学习重新适应。观察指标包括相位切换后的撞墙率（再适应速度）、快/慢思考比例、平均惊讶度（新颖度）与语义记忆的概念生长。选择非平稳环境的理由：静态基准无法区分"背下了答案的系统"和"能持续学习的系统"，只有世界变化才能暴露后者。四个测试文件覆盖学习、记忆与世界模型/元认知的单元行为。

作者明列的已知简化（详见 `v5/README.md`）：巩固用 L2-SP 而非真 EWC/SI；语义记忆目前是参与日志式的支架尚未反哺决策；世界模型是 14 维玩具动力学；**验证闭环是代理指标而非独立评估函数——这是当前最薄弱的一环**。

## 6 跨路线比较与讨论

### 6.1 对照

| 维度 | A（LLM 编排） | B（结构动力学） | C（认知架构） |
|---|---|---|---|
| 有效行为上限 | 高（继承 LLM 语言与知识） | 低但真实（无借用智能） | 中（玩具域内自洽） |
| 安全可控性 | 依赖基准门质量 | 原生可逆性 + 表决（最强理论保证） | 取决于元认知闸门 |
| 个人可复现性 | 需远端 GPU | ✅ 任意 CPU | ✅ 任意 CPU |
| 最大教训 | 数字漂移是权重级的 | 涌现真实但尺度极小 | 验证闭环最难建 |

### 6.2 三点讨论

1. **脚手架收益不对称（路线 A）**：配置迁移实验显示收益随任务族解耦程度衰减。推广之，凡宣称"通用"的自进化改进都应附迁移矩阵，否则可能只是过拟合了某一失败分布。
2. **提示策略存在规模下限（路线 A 负结果）**：思维链在 1.5B 小模型数学任务上系统性有害（最好策略恰是无提示的直接作答）。结合数字漂移个案，我们猜测存在一个模型规模的阈值，低于它时"更多推理步骤"只会放大每步漂移。此假说值得在多尺寸模型上系统复核。
3. **涌现的代价是尺度（路线 B）**：宏工具的诞生证明了结构动力学能产生新功能单元，但从"三个 probe 固化成一个宏"到"通用工具创造"之间隔着巨大的鸿沟。结构路线的价值目前主要在于提供了 LLM 路线无法提供的**对照面**——它告诉我们哪些行为必须依赖参数级知识，哪些确实可以纯靠结构涌现。

## 7 局限性

- 所有实验 n ≤ 数百，无重复测量与显著性检验，结论均为**初步观察**；
- 任务域窄（带校验计算、小学数学、GridWorld），外推性未知；
- 路线 A 依赖的远端实例已释放，完整环境重建依赖 `docs/RESTORE.md`；快照上传前经过脱敏与瘦身（5262→424 文件），令牌/主机名/实例 ID 已替换为占位符；
- 本文及全部代码由 AI 助手在作者指导下完成，可能存在错误与不严谨之处。

## 8 结论与展望

本工作以一个个人仓库的规模，完整走过了"给小模型加脚手架"（A）、"彻底去掉模型"（B）、"重新定义部件"（C）三条路。最主要的收获不是某个 SOTA 数字，而是三组可核对的负面/边界发现：脚手架收益的不对称性、提示策略的规模下限假说、以及验证闭环作为一切自进化系统的共同瓶颈。

下一步（v6 路线图）：① 将路线 B 的表决安全模型移植为路线 A 基准门的候选设计；② 用路线 C 的世界模型替换路线 A 的朴素校验，使守卫从"拦输出"升级为"模型内推演"；③ 为路线 C 补全独立的 critic 头，闭合生成×验证回路。
