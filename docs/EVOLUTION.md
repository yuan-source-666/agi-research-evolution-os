## 各版本速览

| 版本 | 一句话定位 | 智能载体 | 运行要求 | 入口 |
|---|---|---|---|---|
| **v1** | 以 Qwen2.5 为认知核心的多层编排系统：工具调用、反思循环、持久记忆、九层自进化回路 | 一个大语言模型 | SCNet DCU 远端实例（PyTorch 2.9 ROCm） | 精选代码见 `relay/`、`remote/`；复原手册 [docs/RESTORE.md](RESTORE.md) |
| **v2** | SEED OS v2.2：均值场基元社会 + 五条自然规则 + 「语言皮层」（百万级语料 2-gram 联想记忆） | 结构动力学 | 普通电脑，纯 Python 标准库 | `v2/run.py`；架构文档 [v2/architecture.md](../v2/architecture.md) |
| **v3** | 基元社会 v3.1：v2 的机制纯化版——能量经济、法定人数表决、原生安全、词扎根 | 结构动力学 | 同上 | `v3/run.py`；三代对比见 [v3/对比v1-v2-v3.md](../v3/对比v1-v2-v3.md) |
| **v4** | PRIMORDIA v4.1：「结构即智能」的量化证据强化版，每条机制声明附可核对的实验证据 | 结构动力学 | Python ≥ 3.8，零第三方依赖 | `v4/run.py`；[v4/architecture.md](../v4/architecture.md) |
| **v5** | 五件套认知架构参考实现：持续学习引擎、分层记忆、内生世界模型、元认知调度、内生动机 | 认知架构（System 1/2 双系统） | 仅依赖 numpy | `v5/run_tests.py`、`v5/demos/`；[v5/README.md](../v5/README.md) |

## 三条路线的核心分歧

| 问题 | 路线 A（v1） | 路线 B（v2–v4） | 路线 C（v5） |
|---|---|---|---|
| 智能从哪来？ | 大模型参数 + 程序侧脚手架弥补短板 | 结构在时间中的自我优化（无训练、无梯度） | 学习/记忆/世界模型等认知部件的正交组合 |
| 是否依赖现有 LLM | 是（认知核心就是 LLM） | 否（刻意边界） | 否（但预留了 LLM 挂载点作 FastPath） |
| 对话能力 | ✅ 最强项 | ⚠️ 自建语言器官，宽度有限 | ⚠️ 未实现语言层（v6 路线） |
| 在普通电脑可跑 | ❌ 需远端 GPU | ✅ | ✅ |

## 快照的性质与脱敏说明

- `v1/`～`v5/` 是各阶段的**原始工作快照**，保留当时的目录结构与命名，未做美化整理；
  根目录的 `relay/`、`remote/` 则是从 v1 归档中精选重排的可读版本。
- 快照上传前做过严格脱敏与瘦身（5262 个文件 → 424 个）：排除了运行时环境、模型权重、
  大体积数据集、pickle 缓存与日志；API 令牌、集群主机名/用户名、实例 ID、平台端点及本地
  绝对路径均已替换为 `REDACTED_*` / 占位符。因此快照内的脚本**开箱不可直接运行**，
  需按各自文档重建环境。
