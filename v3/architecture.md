# 结构即智能：一个无中心基元社会的 AGI 架构蓝图

> 版本 1.1（对应 v3.1 实现 ｜ 配套实现：`primitives.py`、`evolution_engine.py`、`communication_layer.py`、`run.py`
> 运行要求：任意安装 Python ≥ 3.8 的普通电脑；零第三方依赖；无 GPU；不依赖任何现有 LLM。

---

## 0. 设计立场

本架构不是对一个更大的语言模型的追求，而是对另一种智能存在形态的构造：

> **智能不是参数堆砌，而是结构在时间维度上的自我优化过程。**

由此出发，系统中不存在"被训练的模型"，只存在**正在生活的结构**。系统的全部能力——感知、行动、记忆、语言、工具——都不是预装的模块，而是从一个均匀的基元群体中**自发分化**出来的稳定模式。设计者只提供"物理定律"（五条自然规则）与"化学介质"（共享场），不提供任何控制器、目标函数、损失函数或优化器。

## 1. 总体形态：基元社会 + 共享场 + 自然法则

```
            ┌────────────────────────────────────────────────┐
            │                 外部观察者（人类）                 │
            └───────▲───────────────────────────┬────────────┘
                    │ 自述报告 / 对话 / 纠正       │ 观察与指令
            ┌───────┴──────────┐      ┌─────────▼─────────┐
            │  通信层 Reporter  │◄────►│   解析器 Parser    │
            └───────▲──────────┘      └─────────┬─────────┘
                    │ 只读统计（单向玻璃）          │ 校正脉冲 / 教导注入
  ══════════════════╪═══════════════════════════╪══════════════
  演化引擎（自然法则层，非控制器）                  │
    法则1 赫布加强   法则2 能量竞争   法则3 自适应阈值        │
    法则4 内在可塑性 法则5 侧向抑制   生老病死 / 工具锻造      │
  ══════════════════╪═══════════════════════════╪══════════════
            ┌───────┴──────────────────────────▼────────────┐
            │        基元群体 Population（无层级、平等）         │
            │  sensor ×n  assoc ×n  memory ×n  meta ×n       │
            │  effect ×n（可逆工具执行者 / 宏工具）              │
            └───────┬────────────────────────────────────────┘
                    │ 发射 → 无偏均值聚合
            ┌───────▼────────────────────────────────────────┐
            │        共享场 FieldMedium（K 通道连续介质）         │
            └───────┬────────────────────────────────────────┘
                    │ 观测注入
            ┌───────▼────────┐
            │  环境 ResourceEnv │（演示用不稳定资源世界）
            └────────────────┘
```

三个本体层：

1. **介质层**：K 通道共享连续场。任何基元的影响只能通过场传播。
2. **个体层**：自治基元。每个基元是独立动力学实体，自带基因组（自描述）、局部状态、局部更新规则与能量账户。
3. **法则层**：演化引擎。它不是中枢——它像物理定律一样**对所有基元一视同仁地施加同一条规则**，从不点名、从不排序、从不路由。

## 2. 基元（Primitive）

### 2.1 统一结构

每个基元持有：

| 部分 | 内容 |
|---|---|
| 基因组 Genome | 种类 kind、地址向量 address∈{-1,0,1}^K（嗓音）、增益 gain、初始阈值 θ₀、目标发放率 ρ*、工具名、宏配方、亲代、出生时刻 —— **即自我描述** |
| 局部状态 | 势 p、阈值 θ、能量 e、不应期、爆发值 burst、发放率 EMA、侧抑制待吸收量、键表 bonds |
| 单步预测器 | 对自己最敏感通道的指数滑动预测 → 预测误差 → **胜任度** |
| 行为接口 | `update()` 局部动力学；`emit()` 向场发射；`mutate()` 自我变异；`split()` 有丝分裂；`describe()` 自述 |

### 2.2 五种分化型（由同一基类派生）

- **sensor 感知基元**：把环境观测编码为自己的爆发值射入场中。
- **assoc 关联基元**：纯内部耦合子，占初始多数，是结构生长的主体。
- **memory 记忆基元**：维护自身敏感通道的场历史环形缓冲，低概率"重放"（巩固），供回溯报告引用。
- **meta 监察基元**：接收引擎推送的全局量化快照，是**不可逆操作多层确认**的法定票仓与自述报告的数据锚点。
- **effect 执行基元**：携带工具名（如 `probe`、`nudge_plus`、`macro:稳压三连`），以自身势能提出动议，经**法定人数表决**后执行。

### 2.3 原生安全（编码在定义里，而非外挂过滤器）

安全不写在系统某处的 if 里，而写在基元的类定义中：

1. **可逆性登记**：每个工具在 `ACTION_SPECS` 中声明 reversible。不可逆动作的执行入口在类内部直接检查确认令牌，缺失即抛 `IrreversibleBlocked`——这不是过滤，是该基元"物理上做不出"这个动作。
2. **多层确认**：不可逆请求需同时满足 (a) 监察基元 2/3 法定人数势能过阈；(b) 人类显式令牌；(c) 意图与回滚方案入册。
3. **有界性**：所有状态量（p、θ、gain、ρ*、能量、种群规模）均有硬边界；变异步长有界；宏配方长度 ≤ 3 且仅由已验证的可逆步骤复合而成。

## 3. 通信的唯一方式：无偏均值聚合

**这是全架构最强的约束，也是分化的来源。**

每一拍，场的每个通道取全体存活基元贡献的**算术平均**：

```
field[c] = ( Σᵢ burstᵢ · addressᵢ[c] ) / N        （N = 全体存活基元数）
```

没有加权、没有路由、没有注意力、没有优先级、没有排序选择。沉默者的 0 与喧哗者的 1 以同一分母进入平均。基元间的瞬时影响因此**天然对称、天然无偏**。

那么差异从何而来？答案是经典物理学式的答案：**对称破缺来自动力学，而非接线**。初始微小的随机差异（地址向量、阈值）在场耦合下被五条自然规则放大为宏观结构——正如均匀的流体外涌出对流胞。结构差异全部存储于**基元自身的内在参数**（阈值、增益、目标发放率、生死）与**拓扑关系**（键的存在与否）之中，而不是存储于连接权重之中。

## 4. 五条自然规则（演化引擎施加的统一法则）

引擎每拍对所有基元执行同一套规则；以下为数学形式。

**法则 1 · 赫布加强（结构生长）**
发放时间窗 Δt ≤ 3 拍内共同发放的基元对累计共燃计数；计数 ≥ τ_bond 时缔结一条**键**（无权重的拓扑边）。键决定"谁与谁相邻"，绝不参与信号传播强度的计算。

**法则 2 · 能量竞争（生存筛选）**
能量池每拍向**每个**存活基元发放等额红利（无偏，且仅发放池量的 80%，余量留作储备）；维持、发放、键维护皆耗能（单基元键数有硬上限——结构有界性）。收入有两个来源：其一是环境的**可预测性收益**——世界越平静越可预测，池子进账越多；其二是个体行动的结算——每次集体行动以环境**稳定势**的增量记账，推向低湍区得奖励，反向动作付出代价（有下限）。能量归零者溶解死亡，其键一并拆除；若种群彻底灭绝而储备尚存，「凤凰条款」从池中扣款重新萌发一小群初代基元并记录在案。竞争因此涌现：多一张嘴，每人红利就薄一分；无用结构因收不抵支而自然剪除。**引擎从不排名，淘汰由每个基元自己的账本决定。**

**法则 3 · 自适应阈值（稳态内平衡）**
每个基元把近期发放率 EMA 拉向自身目标率 ρ*：
```
θ ← θ + η·(rate_EMA − ρ*)，  θ ∈ [θ_min, θ_max]
```
过活跃者自动沉默，失聪者自动敏化——群体无需全局调度即可维持动态平衡。

**法则 4 · 内在可塑性（重组创新）**
已发放基元以与自身预测误差（惊讶度）成正比的小概率变异自身基因组：地址向量翻转一位、增益微扰、ρ* 微调。变异有界、随机、局部——新结构由旧结构**生育并突变**而来，而非外部写入。

**法则 5 · 侧向抑制（去冗余）**
基元发放时对其键邻居注入抑制项，邻居下一拍势能扣减之。功能重叠的近邻互相压制，迫使分化——这是竞争抑制在拓扑上的表达。

### 生命周期

- **生（有丝分裂）**：任一基元能量 ≥ 分裂线且种群未满载时自行分裂，亲子各半能量，子代基因组经法则 4 变异。
- **死（溶解）**：能量 ≤ 0 即移除，键同步拆除。
- **凤凰条款**：种群彻底灭绝而池有储备时，扣款萌发一小群初代并记录 PHOENIX 事件——灭绝是事实，不是秘密。
- **长**：分裂偏好性地发生在能量充裕者身上，而能量只流向让世界更可预测的结构——于是**围绕"有用功能"的结构簇自发长大**，这就是成长日志里可见的结构时间线。

## 5. 集体决策：法定人数表决（Quorum）

系统没有决策器。每隔 Q 拍或当集体唤醒度（近 4 拍内至少发放过一次的基元占比）越过触发线时：

1. 所有合格执行基元提交动议，支持度 `support = tanh(rate_EMA / ρ*)` ——以自身目标率为标尺的自校准活跃度，无需全局比较；
2. 合格性由**原生安全层**裁定：能量充足、不在不应期、未命中负校正约束；
3. 取支持度的多数票（并列则公平抽签——仍是无偏聚合）；
4. 可逆动作立即执行；不可逆动作进入第 2.3 节的多层确认管线；
5. 行动以环境稳定势的增量结算，奖励按参与联盟**均分**——问责窗口记录全体参与者，供后续纠正追溯。

人类纠正如何进入演化方向？`纠正：<动作> 不好` 生成**约束记录**（动作族 × 情境签名），此后该情境下的同类动议丧失合格性；同时问责窗内参与者阈值上调（变迟钝）、能量受罚。`表扬：<动作>` 反向：阈值下调、能量奖励。纠正不覆盖任何东西，它作为**新的本地事实**进入每个涉事基元的账本，随后被自然法则放大或遗忘。

## 6. 工具：使用与锻造

- **用器**：执行基元即工具使用者。probe / nudge± 即最小工具集。
- **造器（ToolForge）**：候选配方在独立随机源的克隆环境中干跑+20拍模拟，按稳定势增量评分，择优而生（试错分数入册）。
- **造器（ToolForge）**：锻造炉监视"反复提出却始终得不到足够支持的动议签名"。同一签名冷寂 ≥ 5 次，且历史上有可复用的成功可逆操作序列时，锻造炉将该序列复合为**宏工具配方**（长度 ≤ 3，步步可逆 ⇒ 宏必可逆），在克隆环境中干跑验证通过后，以有丝分裂方式诞生一个新的执行基元。工具的诞生是结构事件，记入成长日志与结构时间线。
- 因此系统能力边界不是静态的：需要什么工具，社会就长出什么工具。

## 7. 透明沟通协议（人 ↔ 基元社会）

语言不是基元的天赋；**Reporter 是架在统计事实上的一块单向玻璃**。一切对外语句均由模板从 `MetricsRegistry` 的量化事实即时渲染——每一个数字都可对照 `growth_log.jsonl` 验证。协议文法（中文优先）：

| 意图 | 触发词 | 回复内容 |
|---|---|---|
| 状态报告 | 报告 / 状态 / 体检 | 种群、键数、连通片、能量池、胜任度、新生/死亡计数、场快照……全部带数字 |
| 解释 | 为什么 / 解释 | 最近一次集体行动的完整因果链：唤醒度、表决边际、参与者、结果收益 |
| 纠正 | 纠正：X 不好(：理由) | 确认约束入册数量、受罚人数、阈值上调幅度 |
| 表扬 | 表扬：X 好 | 同上反向 |
| 教导 | 教：<文本> | 存入记忆基元轨迹并以脉冲注入场，回报注入强度 |
| 工具清单 | 工具 | 已注册工具 + 宏工具配方 + 锻造统计 |
| 节奏 | 加速/减速 n | 演示节奏调整 |
| 暂停/继续 | 暂停、继续 | 冻结/恢复动力学 |
| 帮助 | 帮助 / 指令 | 协议全文 |
| 词汇 | 词汇 / 词表 | 已绑定词与当前最近词（余弦相似度） |

解析失败时诚实告知可用指令集，绝不编造。

**语义萌苽（v3.1）**：教导时把词（「引号内的词」）绑定到当前场模式质心；此后报告会说出当前情境最近的词与余弦相似度——词不是预装的，是经验中被命名的，距离可验证。

## 8. 成长记录规范

- `out/growth_log.jsonl`：每 25 拍一行量化快照（tick、population、by_kind、bonds、components、mean_degree、pool、competence、novelty、coherence、arousal、births、deaths…）——智能曲线与结构时间线的原始数据。
- `out/events.jsonl`：离散事件流（缔结、断裂、出生、死亡、行动、工具诞生、纠正、不可逆请求…），每条带 tick 与细节。
- `out/transcript.jsonl`：全部人机对话实录。
- `run.py --mode live` 提供 ANSI 实时仪表盘（种群/胜任度/唤醒度火花线 + 事件尾 + 最新报告）；headless 结束时打印终期报告。

## 10. 诚实的边界

这是一个**活的雏形**，不是一个已完成的心智：它的语言是模板化的、它的世界是一维的、它的"理解"是动力学的而非符号性的。但它证明了命题本身——不需要中央控制器、不需要权重矩阵、不需要梯度下降，仅凭平等基元 + 均值互作 + 五条自然法则，就能长出分化、记忆、决策、工具与可解释的行为。智能在此不是被训练出来的，而是**长出来的**。后续路线：多维环境、基元间的组合语法、Reporter 渐进习得表达、跨世代谱系选择。
