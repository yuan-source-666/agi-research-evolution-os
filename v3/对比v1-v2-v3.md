# 三代 AGI 实现对比：v1 / v2 / v3

> 基于 2026-08 对项目目录内全部代码的实地勘察（非凭印象）。
> v1 ≈ LLM 编排进化系统（914+365+640+477+367+405+361 行核心 + 远端 GPU 资产）
> v2 = SEED OS v2.2（267+801+417+356+235+172 行，纯标准库）
> v3 = 基元社会 v3.1（308+852+302+337+92+45 行，纯标准库）

---

## 1. 一句话定位

| 代 | 定位 | 智能载体 |
|---|---|---|
| **v1** | 「AGI Research & Evolution OS」：以 Qwen2.5-32B 推理引擎为认知核心的多层编排系统，外挂记忆/工具/世界模型/持续学习/九层自进化回路，跑在 SCNet 远端实例 | **一个大语言模型** |
| **v2** | SEED OS——结构演化型自主智能体：均值场基元社会 + 五条自然规则，另配「语言皮层」（百万级语料的 2-gram 联想记忆）作为语言器官 | **结构动力学** |
| **v3** | 基元社会 v3.1——同一哲学的机制纯化版：能量经济 + 法定人数表决 + 原生安全 + 词扎根 | **结构动力学** |

**血统说明**：v2 → v3 是直接迭代关系（同五规则、同"结构即智能"哲学）；v1 是完全独立的另一条技术路线。

## 2. 核心机制对比

| 维度 | v1 | v2 | v3 |
|---|---|---|---|
| **知识来源** | 32B 模型参数 + GSM8K/ag_news/中英语料微调 | Belle 1M 过滤语料 → 语言皮层倒排索引 | 环境交互经验；词汇靠人类教导绑定（Lexicon 词扎根） |
| **学习机制** | LoRA 微调 + 经验回放 + 技能抽取 | 赫布律强化 gram 共现键 + 同场竞争衰减（遗忘） | 能量经济选择：可预测性收益→红利→有丝分裂；单步预测器自评胜任度 |
| **进化对象** | 九层改进（L1提示词…L9架构），冠军基因组跨周期持久 | 场分裂/合并、键增殖、共激簇固化为工具 | 基元内在参数、键拓扑、种群生死、宏工具配方 |
| **决策方式** | Agent Loop：LLM 生成→工具调用→回喂→终答 | 行动基元高发放提案→通信层安全执行 | 法定人数表决：唤醒度过线→支持度=tanh(rate/ρ*) 投票→联盟均分奖惩 |
| **信号协议** | HTTP/JSON API 调用 LLM | 均值场无偏聚合（emission∈[0,1]，场可分裂合并） | 均值场无偏聚合（±1 地址向量×K通道，通道固定但嗓音可变异） |
| **自我模型** | world_model.py 潜空间预测+想象 | 镜像基元：预测全局均值活性，误差驱动修正 | 每基元单步预测器→胜任度 EMA；监察基元持全局快照 |
| **工具系统** | tool_system.py 标准化执行器（真实联网/计算） | 共激簇固化为 emergent_tool_XX（重放式调用） | ToolForge 监视冷寂动议签名→候选配方克隆环境试错评分→择优诞生宏工具 |
| **安全模型** | 沙箱验证+基准门+接受/回滚，审计日志不可变 | 不可逆动作声明制+多层确认 | **原生安全**：可逆性写在类定义里，无令牌物理上做不出不可逆动作；约束库情境封锁；监察2/3清醒+人类令牌 |
| **记忆** | 分层持久记忆 + 8 个 sqlite 进化记忆库 | 语言皮层（十万级毫秒联想）+ learned_pairs 随教随存 | 记忆基元场历史环形缓冲 + 教导册 + 词汇册 |

## 3. 与《提示词》验收标准的对照

提示词的设计边界：**普通电脑、不依赖现有 LLM、构建自主智能体而非语言模型**。

| 验收条款 | v1 | v2 | v3 |
|---|---|---|---|
| 普通电脑可运行 | ❌ 需远端 GPU 实例 + 294M 资产 | ✅ | ✅（实测 250-400 拍/秒） |
| 不依赖现有 LLM | ❌ 认知核心就是 LLM | ✅ | ✅ |
| 无外部指令自发新结构/行为 | ⚠️ 进化的是提示词/组件配置 | ✅ 场分裂、工具涌现 | ✅ 键网络/宏工具内生（events.jsonl 可查 TOOL_BORN） |
| 自我描述/评估/修正 | ✅（由 LLM 语言能力承担） | ✅ 自发报告+镜像误差 | ✅ describe()+胜任度+自适应阈值（10 项自检可证） |
| 有意义对话 | ✅✅ 真 LLM 对话（最强项） | ✅ 语言皮层四级置信回答（确定/猜测/联想/边缘） | ⚠️ 模板+量化事实+词扎根（诚实但宽度有限） |
| 调用/创建工具、自我学习 | ✅ 工具最丰富（真实联网） | ✅ 涌现工具但为重放式 | ✅ 宏工具参与表决、试错评分择优 |
| 人类纠正纳入演化 | ⚠️ 人工改配置 | ✅ 随教随存最高优先级 | ✅ 约束库情境封锁（实测纠正后归零）+ 问责窗阈值调整 |

## 4. 各代真正的强项与软肋（诚实评估）

### v1 —— 能力最强，血统不符
- **强**：唯一能进行开放式真实对话与真实工具调用的实现；九层进化+回滚的工程纪律完整；证据链归档规范（SHA256 清单）堪称模范。
- **软肋**：它违反了任务书全部三条设计边界。智能不在结构里而在 32B 权重里——把模型拿走，剩下的只是编排骨架。进化回路优化的是"围绕 LLM 的配件"，不是智能本身。

### v2 —— 语言最丰，机制掺金
- **强**：语言皮层是三代中最有趣的语言器官（无嵌入、无回归、纯共现键+四级置信带，"人不因没背过原文就闭嘴"）；场分裂/合并让媒介本身也在演化；自发报告与工具固化有真实生长感。
- **软肋**：energy 只是滚动活性，没有真实的稀缺与生死经济——结构生长缺乏选择性压力；工具固化后只能被人工『调用』，不进入自主决策环；镜像基元的全局均值预测偏宏观，微观归因弱。

### v3 —— 机制最纯，语言最窄
- **强**：①能量是真账本（稀缺红利→无用者死、行动者盛），选择压力第一次真正咬合——实测执行基元占比 19%→45% 全凭经济筛选；②法定人数表决让"决策"成为集体事件且完全可解释（支持度、边际、联盟、收益全可查）；③原生安全写进类定义+纠正情境封锁实测归零；④一切对外语句可对照 JSONL 验证。
- **软肋**：语言宽度远逊 v2 皮层（模板渲染 vs 百万语料联想）；一维环境限制了能"学会"的东西；宏工具目前会刷保底奖励（BASE_R 农耕），需要更锐利的反噬机制。

## 5. 融合建议（下一步的路线图）

三代恰好构成一个分层栈，而不是三个互斥方案：

```
┌─ v1 层：应用外壳 ─────────────────┐
│  chat_relay 式对话接口、真实联网工具、    │
│  benchmark 门、审计日志（工程纪律照搬）     │
├─ v2 层：语言器官 ─────────────────┤
│  language_cortex 作为 v3 的可选器官挂载：   │
│  Reporter 从"只会报数"升级为"带四级置信    │
│  地引用百万语料"；教导册直通皮层 learned_pairs │
├─ v3 层：内核（当前所在）───────────┤
│  基元社会=决策与自我修改的本体；           │
│  一切外部能力（含皮层、v1 工具）都必须      │
│  经执行基元+表决+安全门进入世界            │
└───────────────────────────┘
```

原则：**v3 内核不长大脑，只长肠胃和神经**——语言与知识作为可插拔器官接入，
接入点仍是执行基元与约束库，中心化智能永远不从外部空降。

## 6. 结论

- 论**当下可用能力**：v1 > v2 > v3
- 论**符合任务书哲学**（结构即智能、无 LLM、普通电脑）：v3 ≥ v2 >> v1
- 论**机制的诚实与可验证性**：v3 > v2 > v1
- 论**语言器官的完成度**：v2 > v1 > v3

v3 的赌注是：**选择压力比语言能力更接近智能的地基**。v2 证明了结构会长，
v1 证明了编排能跑，v3 要证明的是——账本和表决就能让结构朝着有用的方向长。
目前的三组实测数据（工具诞生、执行者占比上升、纠正归零）都站在这一边。
