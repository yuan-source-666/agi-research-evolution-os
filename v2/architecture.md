# SEED OS —— 结构演化型自主智能体架构 v2.0

> **Structure-Emerging Evolving Dynamics OS**
> 核心哲学：**结构即智能**。智能不是参数堆砌，而是结构在时间维度上的自我优化过程。

---

## 0. 一句话定位

SEED OS 是一套**无中心、无权重、无外部优化器**的自组织智能体框架。它由自治基元（Primitive）构成，基元之间只通过**均值场（Mean-Field）**交互；结构变化完全由五条自然规则内在驱动。系统运行于普通电脑（纯 Python 标准库，无第三方依赖，无 GPU），不依赖任何 LLM。

```
人类观察者 ⇄ 通信层 ⇄ [ 感知基元 → 均值场 → 计算/行动/镜像/工具基元 ] → 演化引擎 → 成长记录
```

---

## 1. 架构总览

系统由五层构成，各层职责单一，无中心控制器：

| 层 | 组件 | 职责 |
|---|---|---|
| 基元层 | 5 类基元 | 状态保持、局部更新、发出/接收信号 |
| 媒介层 | 均值场 Field | 对成员发射信号做**无偏均值聚合**，是唯一的信号通道 |
| 演化层 | 演化引擎 | 执行五条自然规则，驱动结构生长/剪枝/重组 |
| 通信层 | 通信协议 | 人类 ⇄ 系统双向交互、自述报告、安全执行 |
| 记录层 | 成长记录 | 轨迹 JSONL、事件日志、成长日志、HTML 仪表盘 |

**关键设计约束（对应设计边界）：**

1. **无权重**：任何信号传递都不加权、不路由、不注意力。基元对场的关系只有"在/不在"（结构性成员关系），信号一经发射即以原值进入均值聚合。
2. **无中心**：演化引擎不是控制器，而是规则执行器——它只在每个结构周期末尾应用基元层产生的局部统计量（键强度、活性、相关性），决策依据全部来自基元自身状态。
3. **无外部优化器**：不存在损失函数与梯度。改变结构的唯一驱动力是五条自然规则。

## 2. 基元定义（详见 primitives.py）

所有基元继承自 `Primitive` 基类，具备统一的三元能力：**自我描述、局部状态更新、对外交互**。

### 2.1 状态空间（所有基元共有）

| 状态量 | 含义 | 更新规则 |
|---|---|---|
| `emission` ∈ [0,1] | 当前发射信号强度 | `tanh(gain × input)`（分级发射） |
| `potential` | 膜电位（积分泄漏） | `leak·p + input`，越阈发放 |
| `theta` | 发放阈值 | **自适应阈值**：追踪目标发放率 |
| `gain` | 传递函数增益 | **内在可塑性**：维持输出均值在目标带 |
| `energy` | 滚动平均活性 | 结构增殖/剪枝的依据 |
| `refractory` | 不应期计数 | 发放后 3 tick |

### 2.2 五类基元及特殊相互关系

| 基元 | 特有状态/行为 | 与其他基元的关系 |
|---|---|---|
| **SensoryPrimitive 感知基元** | 符号表 `symbols`；外部符号到达时注入激活 | 唯一的系统入口，只发射不阅读（单向阀门） |
| **NeuronPrimitive 计算基元** | 无附加状态，纯动力学 | 数量最多，是结构生长的主要材料 |
| **ActuatorPrimitive 行动基元** | 动作词表（可逆/不可逆两类） | 高发放时提出动作提案，交给通信层安全执行 |
| **MirrorPrimitive 镜像基元** | 全局状态 EMA 自模型、预测误差 | 观察→预测→比对，是自我评估与自我修正的种子 |
| **ToolPrimitive 工具基元** | `recipe`（结构配方 JSON）+ 可调用算子 | 可由系统涌现创建（见 §4.5），调用即向配方成员注入激活 |

**关系要点**：
- 感知基元是"输入的单向阀门"——外部世界无法直接触碰计算基元。
- 行动基元是"输出的单向阀门"——计算结果只能经行动基元的动作词表作用于世界。
- 镜像基元与全体构成**观察-预测环**：它不断预测下一刻的全局均值活性，预测误差是"智能曲线"的核心分量，也是自我修正的触发器。
- 工具基元与计算基元构成**配方-实例环**：工具是结构的固化快照，调用工具 = 重放该结构模式。

### 2.3 均值互作（Mean-Field）协议

- 每个基元有 `listen_fields`（订阅集合）与 `emit_fields`（广播集合），均为**集合成员关系，无权重**。
- 场信号 = 成员发射信号的无偏算术均值（空场为 0）。
- 基元输入 = 其订阅场信号的无偏均值 − 侧向抑制量。
- **没有任何形式的标量加权、路由、注意力或优先级**。结构的全部信息保存在"谁在哪个场里"这一拓扑中。

## 3. 演化机制（详见 evolution_engine.py）

结构变化由五条自然规则 + 五类结构事件驱动，全部内在，无需外部指令。

### 3.1 五条自然规则（每 tick 局部执行）

| 规则 | 数学形式 | 作用 |
|---|---|---|
| **赫布加强** | `Δbond(i,j) = η·e_i·e_j − δ·bond` | 同场共激基元间的**结构键**（非信号权重）累积 |
| **竞争抑制** | 发放者使场内其他成员阈值临时上浮 | 稀疏化表达，防止全场同涨同落 |
| **自适应阈值** | `θ += α(fire_rate − target)` | 每个基元维持自身目标发放率 |
| **内在可塑性** | `g ← g·(1+β(0.5 − mean_out))` | 增益自调，保持输出在 [0.3, 0.7] 活性带 |
| **侧向抑制** | 发放者向同场均分注入抑制电流 | 邻位锐化，催生表达分化 |

> 注意：结构键（bond）只参与**拓扑决策**（谁该和谁同场），从不参与信号传递——这是"均值互作"与"结构可塑"并存的关键。

### 3.2 五类结构事件（每结构周期 K tick 检查一次）

1. **生长（分化）**：结构键持续超阈的基元对 → 从大场中分出独立新场。结构获得新模块。
2. **增殖（繁殖）**：高能量 + 多超阈键的基元 → 分裂出参数微扰的子代，继承父代订阅。种群增长。
3. **剪枝（凋亡）**：长窗口近零活性的基元转入休眠，休眠超时移除；空场/低流量场解散。资源回收。
4. **重组（融合/裂变）**：两场信号历史相关 > 0.9 → 合并；场内成员活性呈双簇分布 → 裂变。结构再组织。
5. **工具涌现**：含行动基元的稳定共激簇 → 固化为 ToolPrimitive（配方 = 该簇拓扑快照）。系统创建自己的工具。

每个事件都携带**量化缘由**（键强度、相关系数、活性数值）写入事件日志——这是"透明沟通"的基础。

### 3.3 自我修正

镜像基元每周期计算预测误差；误差超阈时，引擎定位偏差最大的异常基元，将其增益向 1.0 回拢、阈值上调（异常阻尼），并以量化理由记录 `self_correction` 事件。

### 3.4 人类纠正的纳入

人类通过通信层发出"纠正"信号后：
- 近期活跃结构键的赫布增长率被放大（valorization）——被纠正时刻的活跃通路获得结构性偏置；
- 对应主题的感知基元目标发放率上调——相关输入通路变得更敏感。
纠正由此**进入演化方向**，而非外挂过滤。

## 4. 通信协议（详见 communication_layer.py）

### 4.1 人类 → 系统

| 消息形态 | 系统行为 |
|---|---|
| 普通文本 | 分词 → 符号哈希 → 感知基元激活（系统"感受到"输入） |
| `纠正: <方向>` | 生成纠正信号，纳入演化（§3.4） |
| `为什么 <id/现象>` | 查询事件日志，返回最近相关结构事件及量化缘由 |
| `状态` / `报告` | 触发完整自述报告 |
| `工具列表` / `调用 <工具>` | 列出/调用工具基元 |

### 4.2 系统 → 人类（自述规范）

自述报告**必须全部由实时状态计算生成**，包含：
- 种群与场的量化快照（数量、均值发放率、活性熵）
- 本周期全部结构事件 + 量化缘由
- 镜像自模型当前预测误差（自我评估）
- 待确认的不可逆动作清单（如有）

报告模板中禁止出现无法由状态验证的形容词。

### 4.3 原生安全模型

安全约束编码在**行动基元的动作词表**中，而非外部过滤器：

- **可逆动作**（直接执行，沙箱内）：写观察笔记、生成报告、固化工具配方、调节自身参数。
- **不可逆动作**（声明 + 多层确认）：删除制品、对外发送。提案进入待确认队列，仪表盘与对话中显式展示，人类逐条确认后方可执行；未确认永不清除。

沙箱目录外的任何写操作在协议层直接拒绝——这不是策略，是词汇表里根本没有这个词。

## v2.3 增补：1G 数据喂养（2026-08-22）

老板指示：「再给我的小种子喂1G数据」。数据源：firefly-train-1.1M（1.17GB / 165 万条）。

- **处理**：165 万条里筛出问答类（OpenQA 百科问答为主），解析「请回答下面的问题」
  模板提取真问题，放宽回答长度至 200 字（中位数 188 字的知乎式回答），与 Belle

- **关键改进——停用 gram 过滤**：大语料下「什么/怎么/如何」等功能词 2-gram 是
  纯噪音（问毛笔字匹配到火车车厢）。STOPGRAMS 集合（约 50 个）在训练/查询两侧
  同步剔除，匹配比的是实义词。实测：废匹配 →「不会」，检索 2.2ms/次（反而更快）。
- **缓存指纹加 CORTEX_VER**：皮层算法变更自动强制重训，不吃旧结构缓存。
- 92k 规模：训练 2.8s / 缓存冷启动 1.0s / 检索 2.2ms / 缓存文件 43MB。

## v2.4 增补：延续的生命（2026-08-22）

实测暴露三个问题：①重启即失忆——每次启动都从 24 基元种子拓扑重新出生，
「智能即历史」沦为口号；②涌现工具从无自主调用（全是 0 次，只有人调）；
③N009 式克隆流水线（同一高能量基元每周期增殖）+ 不可逆提案刷屏（57 条溢出自动否决）。
本次增补主题：**让结构史跨重启连续，让系统真正使用自己创造的东西**。

### 1. 结构快照与苏醒（growth/snapshot.pkl）

- 每 5 个结构周期 + 每次正常退出，原子写入全量结构快照（pickle）：基元动力学状态、
  场成员关系与信号历史、赫布键、ID 计数器、待确认动作、轨迹尾部。
- 启动时若快照存在则**苏醒**（延续 tick/周期/种群，第 N 段连续生命），
  `--fresh` 显式放弃快照重新出生；快照损坏自动退回新生（awaken_failed 事件）。
- 工具闭包不可腌制：快照只存配方与 `_op_kind`，苏醒时由引擎工厂重建算子——
  结构记忆不随进程消亡。
- 轨迹尾部回读：仪表盘智能曲线跨重启连续。
- 新事件 `awaken`（带量化缘由：种群/场/工具/上次存档时间）。哲学对应：
  结构即智能 ⇒ 智能不该死于 Ctrl+C。

### 2. 自主工具使用（镜像驱动闭环）

- 触发器是内部信号：镜像预测误差 > 0.12 时，挑选配方与当前高活性成员
  **拓扑重叠度 ≥ 0.55** 的系统自创工具重放稳定模式（可逆、沙箱内，
  自调用冷却 10 周期）。
- 下周期强制评估（self_tool_evaluation）：误差改善 → 配方成员键各加强 +0.25
  （内在强化，赫布式；键仍只参与拓扑决策）；未改善 → 不加强。
- 实测：tick 40 误差 0.1391 超带 → 重放 emergent_tool_01（重叠 1.0）
  → tick 80 评估 0.1391→0.0058，253 对成员键加强。「创建工具」终于接上「使用工具」。

### 3. 演化健康修正（全部在自然规则层面，无外挂控制器）

| 修正 | 机制 | 针对的病 |

## v2.5 增补：像人一样接话（2026-08-22）

就拒绝说话：人会猜、会联想、会说"我记得大概是"、会用沾边的知识接住话头。

### 1. 分级应答（respond 永远给出回应，不再返回空手）

| 带 | 条件 | 行为 |
|---|---|---|
| sure 确定 | 加权相似度 ≥ 0.42 | 直接断言（背过就直说） |
| guess 猜测 | ≥ 0.24 | 「我记得大概是…」有依据地猜；长回答只取首句——不确信就不背诵长文 |
| associate 联想 | ≥ 0.24 以下且共享词块 ≥4 | 「没正经学过，但让我想起《X》：<第一句>」+ 求教邀请 |

| clueless 认输 | 连两个词块都对不上 | 才真正说不会并求教 |

拉丁字母乱码（asdfghjkl 类）靠共享词块数门槛拦在 associate 之外，
不再出现「乱码联想到充金币攻略」的假自信。

### 2. 对话上下文续接（像人接着话头说话）

- 短追问（≤4 字 / 「那X呢」/「它呢」）不再当全新句子：解析出追问的
  **话题种子**（df≥3 的实义词块，虚字边界碎片如『在高』『原上』被过滤），
  双通道召回含该话题的记忆。
- **问题与答案首句双倒排索引**：话题词常只出现在答案里（『高原』之于
  沸点问答），只索引问题会漏掉一半世界。CORTEX_VER 3→4。
- 排名 = √种子覆盖度 × (0.35 + 0.65×问式重合度) × 置信度：
  覆盖度做一票否决门槛，问式挑出正确意图，键强只做 ±7% 微调——
  语料里的高频幸运儿不许压过语境证据。
- 问式与上一问接近 → 直接断言；否则按猜测口吻交付。实测：
  「光速是多少」→「那声音呢」→ 声速340米/秒；「水的沸点」→「那在高原上呢」→
  高原气压低不到100度就沸腾。检索延迟 ~5ms。
