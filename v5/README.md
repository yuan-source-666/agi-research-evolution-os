# AGI v5 —— “五件套”认知架构参考实现

把一场关于“什么样的架构才算 AGI”的设计讨论，落成可运行的代码。
纯 numpy 实现，零重型依赖；测试与演示开箱即跑。

## 蓝图 → 代码映射

| 对话中的蓝图 | 模块 | 核心机制 |
|---|---|---|
| #1 持续学习引擎 | agi_v5/learning.py | 在线小步更新 + 优先回放 + 周期性 sleep 巩固（L2-SP 锚定） |
| #2 分层记忆系统 | agi_v5/memory.py | 工作/情景/语义/程序四层；显著性淘汰、相似度×近因检索、Beta 技能统计 |
| #3 内生世界模型 | agi_v5/world_model.py | 动力学预测、反事实模拟（想象）、类别 CEM 规划 |
| #4 元认知调度器 | agi_v5/metacognition.py | 快慢路由、三重停车条件（信心/预算/反刍闸门） |
| #5 内生动机系统 | agi_v5/motivation.py | 好奇心（预测误差内在奖励）、目标栈（探索/利用）、胜任感 |
| 快慢思考循环 | agi_v5/thinking.py | System-1 直觉草案 → System-2 模型内验证修正 |
| 认知周期编排 | agi_v5/core.py | 感知→动机→决策→行动→学习→记忆→睡眠 |

三条架构原则的落地：

1. **学习永不停止** —— engine.observe() 对每个转移即时更新，无 train/deploy 分界
2. **双系统** —— FastPath（摊销直觉）+ ThinkLoop（模型内深思）
3. **自适应计算** —— 元认知按“新颖度 × 信心”分配计算时间：难题多想，简单题快答

## 运行

```bash
pip install -r requirements.txt   # 仅 numpy
python run_tests.py               # 单元测试（零依赖运行器，兼容 pytest）
python demos/run_demo.py 600      # 端到端演示
```

演示场景：8×8 非平稳 GridWorld，每 150 步重排墙壁与目标——世界会变，
智能体必须靠持续学习重新适应。观察指标：相位切换后的撞墙率（再适应速度）、
快/慢思考比例、平均惊讶度（新颖度）、语义记忆的概念生长。

## 设计上的诚实标注（简化项）

- 巩固采用 L2-SP 锚定而非真正的 EWC / Synaptic Intelligence——v6 路线
- 语义记忆目前是可观测支架：参与日志、衰减与联想，尚未反哺决策回路
- 世界模型是 14 维玩具动力学：验证的是“在模型内规划”这一原理，不是规模
- 奖励含势能塑形、决策含衰减 ε-贪婪探索——标准 RL 工程实践，不属于架构创新
- 验证闭环是代理指标（预测距离下降 − 惊讶惩罚 − 情景失败惩罚），
  不是独立训练的评估函数——这是当前最薄弱的一环

## v6 路线图

1. 语言接口挂载点：FastPath 可替换为 LLM policy；情景记忆检索结果注入提示词
2. 真·EWC / SI 巩固；经验回放升级为生成式复演
3. 独立的价值验证头（critic），补全“生成 × 验证”闭环
4. 多智能体社会性学习：文化传递作为认知放大器
5. 具身接口（可选）：以真实传感运动流替换 GridWorld 特征
